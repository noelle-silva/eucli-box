# file_reader

`file_reader` 是只读的文本文件与目录查看工具。它通过一个本地工具入口完成读取文件内容、查看目录列表、按通配模式搜索路径和按正则表达式搜索文本。

## 路径行为

- 相对路径从 e-b 宿主运行位置开始解析。
- 绝对路径可以指向当前项目外的文件或目录。
- 实际能访问哪里，仍然受运行进程的操作系统权限限制。
- 本工具为只读设计，不修改、不新建、不删除任何文件。

## 结果信息条

每次成功读取都会在返回正文末尾附一条 `[file_reader]` 信息条，说明本次返回的关键事实（哈希、总行数、续读位置、截断状态、结果数、跳过数等）。输出内容超过上限时优先截断正文，信息条始终保留，方便继续读取或把哈希交给编辑工具使用。

语义说明：

- 输出上限按 UTF-8 字节计（一个中文字约占 3 字节）；截断永远不会切断一个多字节字符。
- `maxOutputChars` 是"正文 + 信息条"的总预算；正文先按预算截断，信息条优先保留。预算极小时正文可能为空，只剩信息条。
- `returnedLines` 指本次窗口返回的行数：行过长被截短时行数不变，用 `lineTruncated=true` 标记；窗口被截断时用 `truncated=true` 与 `nextOffset` 标记。

## 安全边界

- 只处理文本文件；二进制内容和危险空字节会被拒绝。
- 超过大小限制（`maxFileBytes`）的文件会被拒绝。
- 输出内容受到单行字符数、最大输出字符数和最大搜索结果数限制。
- 带 BOM 的 UTF-8 / UTF-16 文本会正确解码并去掉编码标记。
- 无法识别的非 UTF-8 文本（如无 BOM 的 GBK）：坏字节替换为 `�`，正文顶部给出明确警告，结构化信息记录 `invalidUTF8` 与替换数量。

## 操作类型

- `read`：读取文件内容（带行号），或按窗口查看目录内容。信息条返回 `hash`、`totalLines`、`returnedLines`、`nextOffset`。
- `list`：列出指定目录下的条目、类型、大小与修改时间。
- `glob`：按通配模式查找路径。`*` 与 `?` 不跨目录层；`**` 跨层；`**/` 可匹配零层；不带斜杠的模式只匹配搜索根一层（全深度请写 `**/*.go`）。结果按路径字典序返回。
- `grep`：按正则表达式搜索文本文件内容，支持大小写忽略与文件名通配过滤。`include` 不带斜杠时按文件名跨全部层匹配，带斜杠时按相对路径匹配；无法读取而被跳过的文件数量会在信息条中报告。

## 窗口参数

- `offset` 是 1 基行号或条目偏移，`limit` 是返回上限，两者都必须为正数；缺省时使用配置中的默认窗口。
- 读取超过一屏时，用信息条中的 `nextOffset` 继续读取。

## 配置项

- `maxFileBytes`：允许读取的最大文本文件大小。
- `defaultReadLines`：读取或列目录时的默认行数/条目数窗口。
- `maxReadLines`：读取或列目录时的最大行数/条目数上限。
- `maxLineChars`：单行返回内容的最大字节数（按 UTF-8 字节计，截断不切断字符）。
- `maxOutputChars`：单次工具调用返回内容的最大字节数（按 UTF-8 字节计，含末尾信息条；正文先截断）。
- `maxSearchResults`：搜索路径或搜索文本时的最大结果数。
