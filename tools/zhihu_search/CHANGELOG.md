# 更新记录

## 0.2.1 - 2026-10-07

- AI 工具自治改造：脱离宿主依赖、契约包自带并按需精简，工具完全自治

## 0.2.0 - 2026-10-01

- 接入数据迁移模式：宿主携带迁移请求时以独立进程执行自身数据迁移，如实回报结果与数据版本事实，目标数据版本升至 1.2.0

## 0.1.1 - 2026-09-09

- 移除用户配置中的默认时限通道：执行时限只接受调用参数 `timeoutMs`，未指定时限时不设截止时间。

- 建立工具独立版本与 eucli-box 适用范围资料。
