# 更新记录

## 0.3.1 - 2026-10-07

- 系统插件自治改造：脱离宿主依赖、协议与运行契约包自带并按需精简，插件完全自治

## 0.3.0 - 2026-10-01

- 接入数据迁移模式：以专门迁移参数单独启动时执行自身数据迁移并输出结果 JSON 与退出码，目标数据版本升至 1.2.0

## 0.2.1 - 2026-09-22

- 系统插件能力化与协议换代

## 0.2.0 - 2026-09-22

- 升级到系统插件控制通道新协议：握手声明身份与能力、按来源定向取值、限时停机。
- 托管形态改为随业务端启动的常驻插件；抓取与缓存收归插件内部，后台每 30 分钟刷新一次，配置变更立即刷新。

## 0.1.0 - 2026-07-26

- 建立通过和风天气读取天气资料的系统插件。
- 提供详细天气和当前天气简报两个占位符接口。
- 支持城市、密钥、预报范围、预警和空气质量配置。
- 建立插件独立版本与 eucli-box 适用范围资料。
