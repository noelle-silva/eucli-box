# 系统信息插件

系统信息插件用于向系统插件子系统提供当前平台和系统运行信息。

## 提供的占位符接口

- `current-system-info`：默认占位符名为 `system_info`，输出当前平台和系统信息。

## 配置项

- `includeHostname`：是否包含主机名，默认开启。
- `includeUsername`：是否包含当前登录用户，默认关闭。
- `includeEnvironmentSummary`：是否包含常见环境摘要，默认开启。

## 使用方式

1. 打开“设置 → 系统插件管理”，确认“系统信息插件”可用。
2. 按需调整输出内容开关。
3. 打开“设置 → 占位符管理”，从插件接口创建 `system_info` 占位符。
4. 在提示词中使用 `{{system_info}}`。

## 行为边界

- 本插件是按需型插件，只在需要取值时运行。
- 用户名可能包含本机隐私信息，默认不输出。
- 插件不输出当前工作目录，避免暴露本机目录结构。
- 本插件只读取当前运行环境信息，不修改系统设置。
