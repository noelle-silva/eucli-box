# 更新记录

## 0.3.1 - 2026-10-07

- 系统插件自治改造：脱离宿主依赖、协议与运行契约包自带并按需精简，插件完全自治

## 0.3.0 - 2026-10-01

- 接入数据迁移模式：以专门迁移参数单独启动时执行自身数据迁移并输出结果 JSON 与退出码，目标数据版本升至 1.2.0

## 0.2.1 - 2026-09-22

- 系统插件能力化与协议换代

## 0.2.0 - 2026-09-22

- 升级到系统插件控制通道新协议：握手声明身份与能力、按来源定向取值、限时停机。
- 托管形态表达为惰性启动、非长驻；配置在握手与配置变更通知中下发。

## 0.1.1 - 2026-08-08

- 嵌入标准时区数据库，修复 Windows 上无法加载 IANA 时区（如 Asia/Shanghai）的问题。

## 0.1.0 - 2026-07-26

- 建立按需读取当前时间的系统插件。
- 支持预设时间格式和时区选择。
- 提供默认名为 `time` 的占位符接口。
- 建立插件独立版本与 eucli-box 适用范围资料。
