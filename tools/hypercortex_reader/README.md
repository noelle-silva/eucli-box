# hypercortex_reader

`hypercortex_reader` 是 HyperCortex 知识库的只读访问工具。它通过 HyperCortex 应用开放的外部访问入口，完成搜索笔记与附件、读取笔记内容与引用关系、查看收藏夹、附件、版本快照与回收站清单。

## 连接配置

在设置页「AI 工具 → 本工具 → 用户配置」里填写（表单里可直接增删仓库条目，不需要手写 JSON）：

- `访问地址`：HyperCortex 设置页「外部访问管理」里显示的访问地址（配置了开放端口后才可用）。
- `仓库条目`：可增删的多条配置，每条含：
  - `仓库 id`：动作里用 `repo` 参数引用的名字，可含中文；
  - `描述`：给人看的说明；
  - `访问钥匙`：该仓库对应的访问密钥。
- `默认仓库`：动作未指定 `repo` 参数时使用的条目 id。
- `最大输出字符数`（可选）：下调单次输出上限，不能超过随包上限。

一把访问钥匙只通一个仓库；仓库身份由密钥自身决定，工具不会也无法越权指定其他仓库。

## 动作

- `search_notes`：搜索笔记（同一接口，参数区分）：关键词、匹配维度（标题/简介/标签/正文）、面类型、收藏夹范围、更新时间范围、条数与起始位置；不传关键词时按更新时间倒序列出笔记。信息条中 `count` 是本页条数、`total` 是过滤命中总数、`nextOffset` 指示续读；`faceKinds` 是本次实际生效的筛选值（没筛选时不出现），`searchableKinds` 是当前可搜面类型清单。
- `read_note`：读取某篇笔记：笔记信息（标题、简介、标签、时间、版本）与全部面的正文，正文按行全局连续编号；每个面的段落头附带该面的设置（如有）。`dir` 取自搜索结果。可选 `offset`（1 基行号）与 `limit`（行数）续读长笔记，信息条回 `nextOffset`。
- `note_relations`：查看引用 / 被引用关系：关注笔记、半径（跳数，必须大于零，缺省为 1）、方向（双向 / 只看主动引用 / 只看被引用）；大图可用 `section`（nodes / edges）配 `limit` / `offset` 分段读取，不带 `section` 时这两个参数会被拒绝。
- `list_favorites`：查看收藏夹结构与其内容。
- `list_repos`：查看工具配置里注册的仓库条目（仓库 id 与描述，不展示钥匙）；该动作不访问 HyperCortex。
- `search_assets`：搜索附件（名字/备注/标签文本、类型、大小、更新时间范围、分页）；信息条回 `count`（本页条数）与 `total`（命中总数）。
- `list_assets`：查看附件清单 / 信息（按修改时间倒序，支持 `limit` / `offset` 分页续读，信息条回 `count` / `total` / `nextOffset`）。
- `list_trash`：查看回收站（只读；恢复需在 HyperCortex 界面侧的回收站操作）。
- `list_versions`：列出某篇笔记的版本快照（`dir` 必填；返回版本 id、提交名与发布时间，按发布时间倒序）。
- `read_version`：读取某个版本快照的正文（`dir`、`versionId` 必填；与 `read_note` 同一套行流与续读机制，支持 `offset` / `limit`）。

## 输出与边界

- 每次返回（成功与失败）的正文末尾都有一条 `[hypercortex_reader]` 信息条，说明本次调用的关键事实（仓库、动作、条数、行数、续读位置、截断状态等）；信息条不计入输出上限、永久完整。
- 失败信息条携带出错对象标识（`dir` / `noteId` / `faceId`）与机器可读的错误码 `code`（如 `VERSION_CONFLICT`、`NOTE_NOT_FOUND`、`UNKNOWN_FACE_KIND`、`DUPLICATE_FAVORITE`、`PATH_ESCAPE`）；文案可改，码不变，便于程序化区分错误类型。
- 未知参数会直接报错，不会被静默忽略；框架惯例的「调用原因」`description` 被接受并记录到结果元数据（不参与业务，与 `shell_command` 等同款）。
- 正文超出上限时按行边界截断：取预算内最后一个换行处、整行延后（不会砍断编号）；仅当首行本身就超上限时才按字符切。信息条标注 `truncated=true` 与续读位置。
- 分段读取优先用 `limit`（行数 / 条数）：它与内容长度无关、可预期；`maxOutputChars` 只作为总正文上限。
- 正文上限由随包 `config.json` 声明，可在工具用户配置里下调；每次调用还可用可选入参 `maxOutputChars` 再下调（不能突破配置上限）。
- 本工具只读：不创建、不修改、不删除任何内容；删除类动作、附件正文读取与密钥展示都不在本工具范围内。
- 结果中的 `updatedAtMs` 是笔记 / 收藏夹文档的版本标记，后续编辑时可作为防覆盖保险丝回传。
- HTML 面正文不参与搜索（HTML 面是渲染视图外壳，非内容载体）：内容写进 HTML 面后搜不到，但 `write_note` / `read_note` 表现正常；正文内容优先写文本（markdown）面。
- 空面不输出段落头：面计数以信息条的 `faces` 为准。
