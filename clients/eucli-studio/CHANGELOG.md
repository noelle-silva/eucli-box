# 更新记录

## 0.1.9 - 2026-07-26

- 建立客户端独立产品版本和 eucli-box 适用范围资料。
- 所有客户端 HTTP 与事件连接统一携带版本和适用范围。
- 连接时显示客户端版本、eucli-box 版本、所需范围、适用状态和真实原因。
- 版本不适用或尚未完成连接核对时，不创建正常业务界面并拒绝业务请求。
- 修改连接配置后立即清除旧连接状态，重新核对成功后才恢复业务。
- 新增正式版本检查展示：未连接时只检查 eucli-box，连接后展示业务端、AI 工具和系统插件的统一结果。
- 支持主动重新检查，并明确区分检查失败、暂无正式发行、可安装、可更新和已是最新版。
- 版本检查只读取公开发行资料，不下载、不安装或替换程序。
