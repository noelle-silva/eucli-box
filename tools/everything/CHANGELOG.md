# 更新记录

## 0.4.0 - 2026-09-10

- 新增 `action` 输入参数，取值 `search`、`authorize`、`index`，缺省为 `search`；其他取值明确失败。
- 新增 `authorize` 动作：幂等的一次性授权，通过系统提权安装或修复权限管家；已授权时直接返回；不接受搜索专属参数。
- 新增 `index` 动作：复用既有全盘准备路径准备并持久化索引，不执行搜索；不接受搜索专属参数。
- 全盘动作（未指定范围的 `search` 与 `index`）在权限管家不健康时快速失败，并引导先调用 `authorize`、由用户在电脑前确认系统弹窗；指定范围搜索不需要授权。
- 全盘动作绑定配置中的默认实例名；未指定范围的 `search` 显式传入其他实例名时明确失败。
- 权限管家为系统服务（服务名 `Everything (<默认实例名>)`），引擎副本安装于系统保护区的 `eucli-box-everything` 子目录；健康判定覆盖服务存在、登记路径、引擎哈希与运行状态。
- 非 Windows 平台：`authorize` 与 `index` 明确失败，`search` 保持既有行为。

## 0.3.0 - 2026-09-09

- 移除用户配置中的默认时限通道：搜索时限只接受调用参数 `timeoutMs`，未指定时限时不设截止时间。

## 0.2.0 - 2026-09-01

- Everything 运行实例生命周期归入工具调用：默认搜索结束后立即关闭实例，实例存活时间不超过一次调用。
- 新增用户配置 `keepAliveEnabled` 与 `keepAliveSeconds`：开启后实例在最后一次搜索后保持运行指定秒数，超时由工具内置守卫进程自动关闭；关闭开关时数值保留不变。
- 移除项目专属 Windows 服务模式：全盘搜索改为工具专属普通实例方式，不再留下系统级后台服务。

## 0.1.0 - 2026-07-26

- 建立基于 Everything 的本机文件搜索能力。
- 支持默认全盘搜索和指定目录搜索。
- 建立工具独立版本与 eucli-box 适用范围资料。
- 将程序资源归入工具本体，将缓存、索引和运行状态归入长期工具数据区。
