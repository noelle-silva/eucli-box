# eucli-studio 桌面客户端

eucli-studio 是 eucli-box 的桌面操作与展示客户端，负责连接本机业务端、展示业务结果和转交用户操作。

## 使用方式

1. 先启动 eucli-box。
2. 打开客户端并填写 eucli-box 地址；如业务端启用了访问密钥，同时填写密钥。
3. 客户端会先读取双方版本和适用范围。
4. 版本适用且连接成功后，才会进入聊天、设置和其他正常业务界面。

## 版本与连接状态

- 客户端产品版本和所需 eucli-box 范围由客户端发布资料唯一确定。
- 连接页会显示客户端版本、eucli-box 版本、所需范围和真实状态。
- 正常进入客户端后，可以在设置中的 eucli-box 区域再次查看同一份版本与连接事实。
- 无法连接或版本不适用时，连接配置仍可修改，但正常业务不会启动。

## 职责边界

- 客户端不保存另一份业务事实，不替代 eucli-box 做业务判断。
- 客户端后台只负责本地通信、连接核对和展示所需的投影资料。
- 客户端不自动下载、安装、替换或降级 eucli-box。
- 通信规则版本、资料格式版本和产品版本彼此独立，不能混用。

```bash
pnpm exec tsc --noEmit

```

