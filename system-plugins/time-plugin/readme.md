# 时间插件

时间插件用于向系统插件子系统提供当前时间文本。

## 提供的占位符接口

- `current-time`：默认占位符名为 `time`，输出当前时间。

## 配置项

- `format`：时间显示格式，从系统插件管理页的下拉选项中选择，默认“完整日期时间”。
- `timezone`：时区，从系统插件管理页的下拉选项中选择，默认“本机时区”。

## 使用方式

1. 启动业务端后，打开“设置 → 系统插件管理”，确认“时间插件”处于可用状态。
2. 打开“设置 → 占位符管理”，点击“从插件接口创建占位符”。
3. 选择时间插件的 `time` 接口创建占位符。
4. 在提示词中使用 `{{time}}`，发送前会替换为当前时间。

## 行为边界

- 本插件是按需型插件，每次解析需要时间时临时运行一次。
- 如果时间格式不在预设选项内，插件会返回失败。
- 如果时区不在预设选项内，插件会返回失败。
