# 更新记录

## 0.1.1 - 2026-09-30

- 修复参数撞名：笔记简介改为 `noteDescription`、收藏夹说明改为 `folderDescription`，不再与框架「调用原因」的 `description` 惯例冲突（避免把调用原因写进用户数据）。
- `write_note` 增加防误建守卫：只更新已有笔记，目录不存在或归属不匹配时快速失败并提示改用 `create_note`，不再静默创建新笔记。
- 非法面类型（`faceKinds`）由静默丢弃改为直接报错（后端同步修复）。
- 附件类型展示与读工具统一为「kind（mime）」。
- 上传失败时报错明示「源文件不存在」（后端同步修复）。
- 文档补充：保险丝 `expectedVersion` 为可选参数；非法面类型会报错；上传源文件缺失会报错。

## 0.1.0 - 2026-09-30

- 建立 HyperCortex 写入工具：16 个写入动作（选面、新建笔记、整篇写入、精确改字、面顺序、面设置、删面、版本快照、改元数据、上传附件、改附件信息、收藏夹建夹 / 改夹 / 放入 / 移出 / 挪夹）。
- 连接配置与读工具同款（访问地址 / 仓库条目列表 / 默认仓库 / 最大输出字符数）。
- 修改动作统一支持防覆盖保险丝 expectedVersion：版本不一致拒绝写入并回报当前版本，成功后回传新版本。
- 上传附件为同步动作：一次调用等待全部传完，返回附件编号与可直接写入正文的引用标记。
