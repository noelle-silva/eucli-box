# 更新记录

## 0.1.3 - 2026-09-25

- 工作区会话中，相对路径基准改为工作区首个注册目录；非工作区会话回退 e-b 宿主运行位置，行为不变。宿主路径围栏使用同一基准，圈内相对路径不再误报越界。

## 0.1.2 - 2026-09-25

- 声明「工作区路径」能力，接入 AI 工具-宿主运行时协议：路径参数经统一的声明驱动围栏校验；工具行为与结果不变。

## 0.1.1 - 2026-09-11

- 通配查找统一为一个编译型匹配器：`*`、`?` 不跨目录层，`**` 跨层且 `**/` 匹配零层，不再随平台漂移；搜索过滤（include）按文件名跨层匹配。结果改为按路径字典序返回。
- 读取结果末尾新增 `[file_reader]` 信息条：hash、总行数、续读位置、截断与结果数等信息对模型可见；输出截断时信息条不丢。
- 文本解码统一：UTF-8 BOM / UTF-16 BOM 正确解码；非 UTF-8 文本替换为 `�` 并给出警告与结构化标记，不再静默乱码。
- 补丁级修正：glob 遍历只编译一次模式；grep 到达结果上限立即停止；被跳过文件数量可见；read 目录动作名修正；offset/limit 非正值明确报错；截断改为不切断多字节字符。
- 文档澄清（验收反馈）：输出上限按 UTF-8 字节计且含信息条预算；`returnedLines` 为窗口行数，行被截短时用 `lineTruncated=true` 标记，行数不变。

## 0.1.0 - 2026-09-10

- 从 `file_operator` 拆分独立的 `file_reader` 只读文本文件工具。
- 负责 `read`（读文件/目录）、`list`（列目录）、`glob`（路径通配查找）、`grep`（正则文本搜索）操作。
- 独立拥有配置、路径解析、文本安全检查、输出截断与搜索匹配实现，不依赖任何外部工具。
