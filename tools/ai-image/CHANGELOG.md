# 更新记录

## 0.1.1 - 2026-09-30

- 修复配置写入的凭据保护缺口：config_write 与 config_edit 统一收口到同一凭据还原机制，打码 apiKey 写盘前还原为原真实 Key；原配置中没有可保留的真实 Key 时明确拒绝并提示提供明文，不再静默把打码占位落盘为密钥。
- 修复字段级编辑参数指引：config_read / config_write / config_delete / config_edit 缺 file 参数时返回明确提示（含路径示例），不再暴露底层路径清洗文案。
- 修复请求时限语义：timeoutMs 只作用于生图 HTTP 请求（缺省 120 秒、下限 5 秒、上限 1 小时），不再作为整个工具执行的期限打穿控制通道；极小值不再影响本地动作。
- 新增模型列表本地校验：运营商声明了 models 列表时，默认模型与调用覆盖模型都必须在列表内，无效模型本地明确失败并列出可用模型。
- 改进错误反馈：运营商请求失败保留 HTTP 状态码（区分 4xx 参数类与 5xx 服务类）；会话图片引用失败提示可用形式、大小写敏感与清单查看方式。

## 0.1.0 - 2026-09-29

- 从 AI 工具模板建立 ai-image。
- 实现多运营商生图：内置 images、images-edits、chat 三家协议与声明式适配文件；取图支持 URL / base64 / dataURL / JSON 字段。
- 实现配置管理动作（config_list / config_read / config_write / config_delete / config_edit）：直接读写工具自身配置区，校验、大小上限与 apiKey 打码全在工具内部。
- 参考图取自会话图片、生成结果经会话附件写入能力挂回会话；工具只声明会话附件读、写两项能力。
