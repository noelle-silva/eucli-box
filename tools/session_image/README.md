# session_image

会话图片读取工具：传入会话图片 ID，把该图片引用进当前会话。

## 定位

session_image 是工具体系中的独立基础动作：一次调用把会话中已有的一张图片按 ID 引用进本次回复。它存在的目的是让模型能读取超出会话图片预算的历史图片——那些图片在发往模型的请求体里只留有占位文字与图片 ID。

## 动作

- 传入 `imageId`（必填，形态形如 `att-1790722702891563400-6352`，区分大小写）：经会话附件引用能力把该图挂回本次回复。
  - 不落盘：不产生新文件，附件 ID 与路径不变。
  - 引用结果由宿主挂回本次回复；原图仍在发送预算内时，上下文中出现两张相同图片属预期。
  - 失败分级：ID 格式不合法（含大小写不符、截断）在本地直接拒绝并给出正确形态；ID 不存在由宿主回执。

## 能力

只声明一项能力：`session-attachments:reference`（引用会话图片），需用户在工具设置页开启授权。

## 边界

- 不做图片生成、不做图片编辑、不做配置管理。
- 只引用会话中已存在的图片，不接触物理路径。
