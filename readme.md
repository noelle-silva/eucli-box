# eucli-box

eucli-box 是一个本地 AI 工作台后端与配套工具集合，负责角色、会话、模型供应商、工具调用、表情包和辅助生成能力的数据保存与服务暴露。

## 数据目录约定

- `data/` 是运行期数据目录，不是源码目录。
- `data/meta/` 只用于保存长期辅助信息，例如版本标记、功能偏好和模型分组等稳定配置。
- 模型请求过程不再默认落成独立流水文件，避免运行期目录持续积累无下游消费的小文件。
- 历史遗留的请求流水文件不会再新增，可在确认不需要追查旧请求后单独清理。

## 维护原则

- 长期设置和短期运行痕迹分开处理。
- 没有真实下游消费的数据不默认持久化。
- 如未来需要请求诊断能力，应重新设计为可开启、短期保存、可自动清理的独立诊断机制。

## 回复生成约定

- 重新回复基于目标回复之前的完整聊天上下文重新生成，不要求目标回复前一段必须是用户发言。
- 重新回复生成的新内容继续沿用现有路线分支行为，不覆盖被重新生成的旧回复。
- 从用户消息继续回复仍保持原语义，只基于该用户消息所在的上下文继续生成。
