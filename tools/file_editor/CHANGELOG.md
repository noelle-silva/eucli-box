# 更新记录

## 0.1.1 - 2026-09-11

- 补丁引擎重写：每个 `@@` 段独立定位并按顺序应用，段与段之间可以有间隔；空行按空上下文行对待；语法不合规明确报错（结束标记后内容、`@@` 后内容、新增/删除段带移动指令、删除段带正文、非法行前缀）；同一文件在一份补丁里仍只允许出现一次。
- 换行风格适配：编辑与补丁按文件自身的 LF/CRLF 风格匹配与写回，不再出现"读到的内容能改不动"；新建文件使用 LF。
- 写入安全：改为同目录临时文件 + 改名就位，失败不留半截文件并保留原文件权限；补丁回滚失败与原始错误一起上报。
- expectedHash 收口为单一校验：传入时目标必须存在；失败统一回报当前真实 hash；写入、编辑与创建路径共用。
- 结果末尾新增 `[file_editor]` 信息条，新 hash 等信息对模型可见，可直接串联到后续 expectedHash。

## 0.1.0 - 2026-09-10

- 从 `file_operator` 拆分独立的 `file_editor` 文本编辑工具。
- 负责 `write`（新建或整体覆盖）、`edit`（精确文本替换）、`apply_patch`（结构化补丁）操作。
- 独立拥有配置、路径解析、文本安全检查与补丁先规划后写入实现，不依赖任何外部工具。
