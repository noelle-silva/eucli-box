# 更新记录

## 0.2.0 - 2026-09-22

- 升级到系统插件控制通道新协议：握手声明身份与能力、按来源定向取值、限时停机。
- 托管形态表达为惰性启动、非长驻；配置在握手与配置变更通知中下发。

## 0.1.1 - 2026-08-08

- 嵌入标准时区数据库，修复 Windows 上无法加载 IANA 时区（如 Asia/Shanghai）的问题。

## 0.1.0 - 2026-07-26

- 建立按需读取当前时间的系统插件。
- 支持预设时间格式和时区选择。
- 提供默认名为 `time` 的占位符接口。
- 建立插件独立版本与 eucli-box 适用范围资料。
