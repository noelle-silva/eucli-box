# 更新记录

## 0.2.1 - 2026-10-07

- AI 工具自治改造：脱离宿主依赖、契约包自带并按需精简，工具完全自治

## 0.2.0 - 2026-10-03

- 参考 Scrapling，在纯 HTTP 层增强反封锁能力：内置 Chrome、Firefox、Edge 多套浏览器身份与请求头，按请求随机切换。
- 接入 TLS 指纹伪装：握手层模拟对应浏览器的密码套件、扩展顺序与 HTTP/2 指纹。
- 新增封锁识别与退避重试：识别 401/403/407/429/444/5xx，命中后换身份按退避等待重试，支持 Retry-After。
- 新增运行时配置 `proxyUrl`（TLS 指纹客户端不自动读取系统代理环境变量）。
- 输出元数据新增 `profile`（本次浏览器身份）与 `attempts`（实际请求次数）。

## 0.1.0 - 2026-10-02

- 从 AI 工具模板建立 `web_fetch`，实现获取指定 HTTP(S) 网址内容的基础动作。
- 网页内容转换为 Markdown，其他文本原样返回，并附外部内容不可信提示。
- 建立网址校验、系统代理自动适配、有界读取与编码解码。
- 支持请求时限、输出长度与原因说明配置。
