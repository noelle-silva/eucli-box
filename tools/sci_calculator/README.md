# 科学计算工具

`sci_calculator` 是 eucli-box 使用的科学计算工具，用于计算数学表达式、常用函数、统计量、积分、置信区间和误差传播。

## 使用能力

- 支持常见四则运算、幂、取余和整除。
- 支持三角函数、平方根、对数、指数、绝对值和取整。
- 支持均值、中位数、方差、标准差等统计计算。
- 支持概率辅助、定积分、置信区间和误差传播。

## 运行环境

- 正式工具包优先使用随工具本体提供的 Python 运行环境。
- 开发态或未附带运行环境时，可以通过用户配置指定 Python。
- 外部 Python 需要提供工具所依赖的科学计算库。

## 输入与输出

- `expression`：必填，要计算的完整表达式。
- `maxOutputChars`：可选，限制返回内容长度。
- `description`：可选，说明本次计算目的。

计算结果会以工具统一结果格式返回，并明确说明失败原因。

## 资料边界

- 工具声明、程序和默认配置属于工具本体。
- 用户选择的 Python 和输出限制属于长期工具数据。
- 重新建立工具本体不会覆盖用户配置。
- 本工具只负责一次计算，不负责维护表格、笔记或长期计算任务。
