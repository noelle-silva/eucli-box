# _tool_template

`_tool_template` 是 AI 工具基础模板：不含任何业务功能，具备 AI 工具的全部公共底座。

## 公共底座

- 被宿主调用的标准入口：从标准输入读取执行输入、回传结构化结果。
- 宿主控制协议接入：身份握手与心跳保活；需要输出进度上报或运行中能力交互的新工具，按需在本地协议包补充对应消息。
- 数据迁移骨架：首次运行写入数据版本事实；数据版本升高时沿已登记步骤逐级迁移并核对。
- 随包结构：`toolpack.json` 声明外部程序捆绑与运行时配置，新工具需要携带外部程序时按同一结构声明。

## 使用方式

整份复制模板并实现业务动作，即成为新的 AI 工具。复制与身份改写由脚手架统一完成：

```
.dev-tools/eucli-tool-scaffold/create-tool.cmd -id my_tool -name my_tool -description "工具描述"
```

脚手架会自动改写目录名、清单身份、import 路径与文档，生成后不需要手工修补身份信息。

## 目录结构

- `cmd/_tool_template/`：入口、控制协议接入与数据迁移登记。
- `internal/tooltemplate/`：业务动作所在位置；模板中明确返回「未实现」失败。
- `internal/datamigration/`：数据迁移骨架，与各工具同源。
