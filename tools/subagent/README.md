# subagent

把一条消息真正发给指定角色，等它整轮停下后取回它最新的回复。

## 动作

唯一动作是请求「发送会话消息」能力，其余全部交给宿主：消息怎么进会话、运行怎么起、什么时候算停下、取消怎么落地，工具都不参与。

| 参数 | 必填 | 含义 |
| --- | --- | --- |
| `roleId` | 是 | 目标角色 ID |
| `message` | 是 | 要发出去的消息内容 |
| `sessionId` | 否 | 留空即新建会话；填写则续接该会话继续追问 |
| `workspaceId` | 否 | 留空是普通会话；填写则在指定工作区的会话里发言 |

结果带回会话标识、消息标识、角色标识与角色最新回复的全文。

## 边界

- 不查角色清单、不拼提示词、不判断对方是否该回应：这些不属于发送动作。
- 角色或会话不存在、等待期间被取消，都由宿主裁决，原因原样带回，工具不翻译也不掩盖。
- 没有宿主控制通道时（独立运行）明确失败，不伪造一条回复。
