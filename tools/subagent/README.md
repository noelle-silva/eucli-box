# subagent

把消息真正发给指定角色并取回它最新的回复，或按当前工作区列出可用的角色。

## 动作

### send（默认）

唯一外部动作是请求「发送会话消息」能力，其余全部交给宿主：消息怎么进会话、运行怎么起、什么时候算停下、取消怎么落地，工具都不参与。

| 参数 | 必填 | 含义 |
| --- | --- | --- |
| `roleId` | 是 | 目标角色 ID |
| `message` | 是 | 要发出去的消息内容 |
| `sessionId` | 否 | 留空即新建会话；填写则续接该会话继续追问 |
| `workspaceId` | 否 | 留空即沿用当前工作区（工作区会话里由宿主注入）；普通会话留空即普通会话；只有要发给别的工作区才显式填写 |

结果带回会话标识、消息标识、角色标识与角色最新回复的全文。

### list

按范围列出角色名、角色标识与角色描述。

范围不由工具猜：工作区会话里，宿主会把当前工作区标识注入到工具（`workspaceId` 字段），工具带着它向「读取角色名册」能力索取，拿回注册在该工作区的角色；普通会话里没有注入，工具不带工作区标识，拿回宿主注册的全部角色。

## 边界

- 不查角色清单以外的事实、不拼提示词、不判断对方是否该回应。
- 角色或会话不存在、名册能力未授权、等待期间被取消，都由宿主裁决，原因原样带回，工具不翻译也不掩盖。
- 没有宿主控制通道时（独立运行）明确失败，不伪造名册、不伪造回复。
- 工作区注册表里残留的已删角色由宿主跳过，不阻断整份名册。
